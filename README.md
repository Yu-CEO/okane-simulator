# おかね収支シミュレーター

NISAの積立と、区分マンションの毎月の収支を、ブラウザだけで計算できるシンプルなツールです。NISA積立には、GPIF（年金積立金管理運用独立行政法人）の資産ごとの運用実績で試算する「過去の実績で計算する」もあります（v2.1）。画面は初心者向けの型（v2.2）で、「毎月3万円を20年続けたら、いくらになる？」という問いかけから始まります。

## できること
- **NISA積立**：毎月の積立額・年数・想定利回りから、将来の金額と元本を計算します（非課税枠の上限を超えると注意を表示）
- **NISA積立（過去の実績で計算する）**：上の切り替えで選びます。国内株式・外国株式・国内債券・外国債券（いずれも「年金の運用実績」）から1つ選び、毎月の積立額・信託報酬など（初期値0）・運用開始年度・終了年度・口座（NISA／課税口座）を入れると、元本・最終額・増えた額を出します
  - 終了年度が実績のある最後の年度（2025年度）より後のときは、最終額を「下 〜 上（中央）」の幅で出します（1本の数字にはしません）。幅は、過去の年度ごとの収益率の幾何平均と標準偏差から作ります（乱数は使わないので同じ入力なら同じ結果）
  - 課税口座は、終了年度の末に一括で売る想定で、増えた額に約20.315%の税金を引きます
  - 出典（GPIFウェブサイトのURL・資料名・確認日）と、年度ごとの収益率の表（「くわしく知りたい人へ」の中）を表示します
- **マンション収支**：家賃・空室率・ローン・管理費などから、毎月と年間の手元のお金（キャッシュフロー）を計算します
- **空室時の家賃保証**：チェックを入れると、空室の期間も「家賃 − 差し引かれる額」が入る想定で計算します（差し引かれる額が家賃より大きいときは、空室の月の入金を0として計算）

## 使い方
1. `index.html` をブラウザで開きます（ダブルクリックでOK。サーバー・インストール・インターネット接続はいりません）
2. 最初は積立の画面です。マンション収支は、ページ下の「ほかの計算」のボタンから入ります（「← 積立の計算に戻る」で戻れます）。積立では「毎月いくら・何年」を、よく使う値のボタンか数字で入れ、「利回りを自分で入れる」（最初の表示）と「過去の実績で計算する」を切り替えられます。出典・計算のしかたは「くわしく知りたい人へ」に畳んであります
3. 数字を入れると、その場で結果が変わります（計算ボタンはありません）
- 空欄やマイナスの数字は 0 として計算します
- 入力した内容は保存も送信もしません

## テストの実行方法
計算の部分は、ブラウザなしで自動テストできます。Node.js（バージョン20以上）が必要です。外部ライブラリは使いません。

リポジトリを取ってきたフォルダ（`index.html` があるフォルダ）で、次を実行します。

```
node --test
```

`tests/` の中の `*.test.js` がすべて実行され、最後に `fail 0` と出れば合格です。

## 注意
- 入力された数字をもとに計算するだけのツールです。投資の助言ではありません。特定の商品や売買をすすめるものではなく、将来の結果を約束するものでもありません。
- 所得税・住民税の増減（減価償却などの節税効果）は含みません。
- 家賃保証の条件（差し引かれる額・免責期間など）は契約によって違います。
- 実際の判断はご自身の責任で、必要に応じて専門家にご相談ください。
- 「過去の実績で計算する」は、GPIF の資産ごとの運用実績を使った試算です。個人が買える特定の商品の成績ではなく、特定の商品をすすめるものでもありません。このツールは GPIF とは関係ありません。年度は4月〜翌年3月です。
- 年金の運用実績は運用手数料等の控除前の数字です。個人が払う信託報酬は、入力欄で自分の値を入れると差し引きます。
- 将来の幅は「過去の実績をもとにした計算」です。将来の結果を保証するものではなく、実際には幅の外になることもあります。
- 課税口座の税金は目安です（分配金・売る時期・損益通算などで実際の税額は変わります）。
- データは手で入力したものです。入力元は `docs/data_sources.md` を見てください。
