# おかね収支シミュレーター

NISAの積立と、区分マンションの毎月の収支を、ブラウザだけで計算できるシンプルなツールです。

## できること
- **NISA積立**：毎月の積立額・年数・想定利回りから、将来の金額と元本を計算します（非課税枠の上限を超えると注意を表示）
- **マンション収支**：家賃・空室率・ローン・管理費などから、毎月と年間の手元のお金（キャッシュフロー）を計算します
- **空室時の家賃保証**：チェックを入れると、空室の期間も「家賃 − 差し引かれる額」が入る想定で計算します（差し引かれる額が家賃より大きいときは、空室の月の入金を0として計算）

## 使い方
1. `index.html` をブラウザで開きます（ダブルクリックでOK。サーバー・インストール・インターネット接続はいりません）
2. 上の「NISA積立」「マンション収支」ボタンで画面を切り替えます
3. 数字を入れると、その場で結果が変わります（計算ボタンはありません）
- 空欄やマイナスの数字は 0 として計算します
- 入力した内容は保存も送信もしません

## テストの実行方法
計算の部分は、ブラウザなしで自動テストできます。Node.js（バージョン20以上）が必要です。外部ライブラリは使いません。

リポジトリを取ってきたフォルダ（`index.html` があるフォルダ）で、次を実行します。

```
node --test
```

`tests/` の中の `*.test.js` がすべて実行され、最後に `fail 0` と出れば合格です。

## ファイルの地図
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（入力欄・結果欄・注意書き）と、下のファイルの読み込みだけ |
| `css/style.css` | 見た目（色・余白・文字の大きさ） |
| `js/format.js` | 金額の表示形式（万円・小数第1位・カンマ・「−」）と、入力値を数字に直す処理 |
| `js/nisa_calc.js` | NISA積立の計算と、注意文を出す条件の判定（画面には触れない） |
| `js/realestate_calc.js` | マンション収支の計算（返済額・入る家賃〈家賃保証の有無〉・出るお金）（画面には触れない） |
| `js/nisa_view.js` | NISAの入力欄を読み、結果と注意文を画面に表示する |
| `js/realestate_view.js` | マンションの入力欄を読み、結果を表示する（プラスは緑・マイナスは赤、家賃保証の欄の出し分け） |
| `js/tabs.js` | タブの切り替え |
| `js/main.js` | 入口。入力のたびに再計算する設定と、最初の計算 |
| `tests/format.test.js` | 表示形式のテスト |
| `tests/nisa_calc.test.js` | NISA計算のテスト（受け入れ基準 AC-1〜4） |
| `tests/realestate_calc.test.js` | マンション収支のテスト（AC-6・7・8・8a・8b・15） |
| `ci/confidential_check.py` | 機密の言葉が入っていないかのチェック（テンプレートのコピー） |
| `docs/` | 要求仕様（`requirements.md`）・レビューや動作確認の結果 |
| `.gitignore` | GitHubに上げないファイル（秘密の設定・ログなど）の一覧 |

`js/` の計算ファイル（`format.js`・`nisa_calc.js`・`realestate_calc.js`）は、ブラウザでは普通の `<script>` として、Node.js では `require` で読み込める形にしています。

## 注意
- 入力された数字をもとに計算するだけのツールです。投資の助言ではありません。特定の商品や売買をすすめるものではなく、将来の結果を約束するものでもありません。
- 所得税・住民税の増減（減価償却などの節税効果）は含みません。
- 家賃保証の条件（差し引かれる額・免責期間など）は契約によって違います。
- 実際の判断はご自身の責任で、必要に応じて専門家にご相談ください。
